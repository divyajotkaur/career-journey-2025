# AZ-900 Week 1 Notes  
**Focus: Cloud Concepts & Core Services**
 
---
 
## ☁️ Cloud Concepts
- **IaaS (Infrastructure as a Service)** → User manages OS, runtime, apps. (e.g., Azure VM).  
- **PaaS (Platform as a Service)** → Azure manages infra + runtime. User focuses on code. (e.g., Azure App Service).  
- **SaaS (Software as a Service)** → Complete product delivered. (e.g., Teams, Outlook, Gmail).  
 
- **CapEx vs OpEx**  
  - CapEx = upfront investment (servers, datacenter).  
  - OpEx = pay-as-you-go (Azure services).  
 
- **Shared Responsibility Model**  
  - On-Prem → you manage everything.  
  - Cloud → responsibility shifts depending on IaaS, PaaS, SaaS.  
 
---
 
## 🔑 Core Azure Services
- **Compute**
  - **VMs** → customizable servers.  
  - **App Services** → host web apps easily (PaaS).  
  - **Functions** → serverless, event-driven code execution.  
 
- **Storage**
  - **Blob Storage** → unstructured data (images, docs, backups).  
  - **File Storage** → SMB protocol, like a file share.  
  - **Queue Storage** → message-based communication between components.  
 
- **Networking**
  - **VNet (Virtual Network)** → isolate & secure network in Azure.  
  - **VPN Gateway** → secure connection between on-prem & Azure.  
  - **ExpressRoute** → private dedicated fiber connection to Azure.  
 
---
 
## 🌍 Global Infrastructure
- **Regions** → geographical areas (e.g., Central India, East US).  
- **Availability Zones** → physically separate datacenters in a region.  
- **Region Pairs** → disaster recovery setup (two regions in same geography).  
 
---
 
## ⚡ Benefits of Cloud
- High Availability  
- Scalability (vertical = bigger machine, horizontal = more machines)  
- Elasticity (auto scale up/down as needed)  
- Agility (quick deployment)  
- Disaster Recovery
